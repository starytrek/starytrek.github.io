HTML po ludzku
HTML
Język opisujący strukturę i znaczenie treści strony. Nie jest językiem programowania.
znacznik
Instrukcja w nawiasach < >, np. <p> rozpoczyna akapit.
atrybut
Ustawienie znacznika, często nazywane parametrem. W href="kontakt.html" atrybut to href.
wartość
To, co przypisujesz atrybutowi. W href="kontakt.html" wartość to kontakt.html.
href
Dokąd prowadzi odnośnik <a>. Przykład: href="kontakt.html".
src
Skąd pobrać obraz lub inne źródło. Przykład: src="kot.svg".
alt
Tekst zastępujący obraz, np. alt="Rudy kot Felek". Pomaga, gdy obraz nie działa, i osobom korzystającym z czytnika ekranu.
id / class
id identyfikuje jeden element (np. kontakt). class łączy elementy w grupę (np. karta).
head / body
head zawiera informacje o dokumencie; body — treść widoczną na stronie.
CSS
Język wyglądu: kolorów, odstępów, rozmiarów. HTML opisuje treść, CSS nadaje jej wygląd.
